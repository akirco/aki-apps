## Cubo (Bucket) de Scoop `aki`

`scoop bucket add aki 'https://github.com/akirco/aki-apps.git'`

## Módulo de PowerShell recomendado

1. [scoop-search](https://github.com/akirco/dotfiles/blob/master/powershell/modules/scoop.psm1)

> mejora la búsqueda de scoop, agrega búsqueda remota e instalación de archivos manifiestos remotos

```powershell
scoop search rust

# lista de aplicaciones locales (rápido)
# lista de aplicaciones remotas

scoop add RepoName/appName
scoop install remote/appName

# remote es el directorio predeterminado
```

2. [hosts](https://github.com/akirco/powershell/tree/master/hosts-editor)

```powershell
hosts -cat # mostrar archivo hosts local

hosts -up  # descargar archivo hosts de <521xueweihan/GitHub520> para actualizar hosts local

hosts -add <domain> # obtener IPV4 e IPV6 del dominio desde https://sites.ipaddress.com y agregar al hosts local
```
